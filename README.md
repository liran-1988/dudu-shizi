# 嘟嘟识字 · PWA 1.4.0

访问：https://liran-1988.github.io/dudu-shizi/

Android 使用 Chrome、iPhone/iPad 使用 Safari 打开，再添加到主屏幕。首次点开声音并检查媒体音量；无普通话语音时可看字找字。核心网页缓存可离线，系统声音与可选联网服务另受设备条件影响。

成长路线：启蒙园 → 生活发现 → 词句小伙伴 → 阅读小探险 → 进阶挑战。字量是可体验字库，不是中班统一达标或小学阅读能力认证。

更新后长按右上 ⚙️ 3 秒 → 检查更新 → 确认。不要为更新先清网站数据，以免丢失本机记录。

每批 5/10/15/20 字默认 10，每日 3/5/10 轮默认 5。再练一练有分级错题本，家长可看统计、调整有效答对移出门槛。

只维护 PWA，不提供 APK。此仓库为生成发布资源；相关方案、完整字表和词句表可供家长、教师查看。

构建/逻辑与浏览器模拟已验证，不代表全部手机音质、系统语音包或真实儿童学习效果已验证。
